How to subscribe
  • iPhone / iPad: tap Subscribe above and confirm.
  • macOS Calendar: File → New Calendar Subscription, paste the link.
  • Google Calendar: Other calendars → + → From URL, paste the link. Google refreshes external feeds on its own schedule, often only every 8–24 hours.
  • Outlook: Add calendar → Subscribe from web, paste the link.

Subscribe, don't import — importing copies the events once and they never update.
